## Architecture docs: `./architecture` folder

- Do not add implementation details into architecture documents.
  Treat them as if there could be multiple independent implementations of this architecture.
  Public interface is the only implementation detail that could be exposed.
- Do not describe implementation status, rollout stages, or temporary limitations
  in architecture documents.
  Status of architecture documents themselves is fine.
- File `./architecture/overview.md` always contains the latest information.
  Keep other documentation consistent with it when there are conflicts in docs structure or content.
